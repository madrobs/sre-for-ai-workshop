# 45-minute spine

1. Hook (5) — Failure that was not in the app logs. SRE made systems legible; that is what AI needs.
2. Three headlines (5) — Declare / encode standards / encode response.
3. Round 1 (8) — Logs + app only. Let the room (and any agent) fail.
4. Round 2 (10) — Full `chalkline-receipts` clone. IAM + `git show`.
5. Name the pattern (8) — Map the incident to the three headlines; show the five-question checklist.
6. Their org (7) — One production mystery from last quarter. Which question was missing?
7. Close (2) — GitHub for afterward; runbook story if time. AI does not replace SRE. Undocumented systems starve both humans and agents.
