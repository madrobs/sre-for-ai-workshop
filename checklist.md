# Takeaway checklist

If an agent or a new teammate cannot answer without pinging a human, the system is not ready for them — or for AI.

1. Where is desired state declared? (IaC)
2. Where is the story of what changed? (git history)
3. Where are our real standards enforced — lint, CI, the “don’t do this” rules? (checks)
4. Where do we see the system running? (observability)
5. Where is the path for the next human when this fails? (runbooks)

Opening slide (three headlines, same stack):

1. Declare the system — IaC, versioned history
2. Encode the standards — lint, CI, tribal rules as checks
3. Encode the response — observability + runbooks

Workshop demonstrates 1 (and git). Runbooks are the security-lockdown story on slides, not this incident.
